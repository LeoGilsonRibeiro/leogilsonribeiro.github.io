### Tipos de erros mais frequentes

- **Letras trocadas ou omitidas:** `Triste` → `Trieste`, `stamos` → `estamos`, `carto` → `cargo`, `Sfresa` → `Stresa`, `toas` → `todas`
- **Nomes próprios deformados:** `Vittorino` → `Vittorini`, `Baashevis` → `Bashevis`, `Jacapone` → `Jacopone`, `Rosselini` → `Rossellini`, `Ungaratti` → `Ungaretti`, `Lempedusas` → `Lampedusas`, `Caltellaneta` → `Castellaneta`, `Spngler` → `Spengler`
- **Nomes de obras com erros:** `*Ragioni di uma Poesia*` → `*una*`, `*Il Pendulo di Foucault*` → `*Pendolo*`, `*Hier est kei Warum*` → `*Hier ist kein Warum*`
- **Palavras faltando ou substituídas:** `loso` → `logo`, `Teho` → `Tenho`, `cosas` → `coisas`, `trai-los` → `traí-los`
- **Frases com palavra omitida:** `a chega à Índia` → `a chegada à Índia`, `Enlaçou-a pintura` → `Enlaçou-a pela cintura`
- **Erros semânticos graves:** `Prêmio Cabra-Cega … Prêmio Novel` → `Prêmio Nobel`, `mancha de trinta` → `mancha de tinta`, `reator os laços` → `reatar os laços`, `vão recorrer os feridos e os mortes` → `vão recolher os feridos e os mortos`
- **Erros de concordância/preposição:** `surda à misérias` → `às`, `impregnado o sentimento` → `do`, `aderindo a a uma` → `a uma`
- **Expressões estrangeiras deformadas:** `*sotto você*` → `*sotto voce*`, `*andaimo*` → `*andiamo*`
